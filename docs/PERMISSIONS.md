# 权限与隐私边界

## 当前需要

- 本机端口 `5173`：开发页面。
- 本机端口 `8787`：LifeOS API。
- 本机端口 `11434`：Ollama。
- 本机端口 `50060`：WhisperKit 语音识别。
- 项目目录读写：保存代码、Markdown 和构建文件。

所有服务默认只绑定 `127.0.0.1`，不会直接暴露到局域网或公网。

## 当前不需要

- 不需要 macOS 完全磁盘访问。
- 不需要管理员密码。
- 不需要云模型 API Key。
- 不需要 GitHub 登录。
- 不需要开放摄像头、麦克风、定位或通讯录。

语音模式首次开启时需要允许浏览器访问麦克风。麦克风只在用户主动点击语音按钮后启用；原始录音只临时用于转写，不写入资料库。

## 已设置的用户级自动启动

- `com.lifeos.local`：登录 macOS 时启动 LifeOS 本地服务，只监听 `127.0.0.1:8787`。
- `com.lifeos.whisper`：登录 macOS 时启动 WhisperKit 本地语音识别，只监听 `127.0.0.1:50060`。
- `com.lifeos.stickies`：登录 macOS 时自动打开系统“便笺”。

该任务位于 `~/Library/LaunchAgents/`，只作用于当前用户，不需要管理员权限。

## 以后需要用户确认的项目

- 登录 GitHub 并授权仓库访问。
- 添加云端模型 API Key。
- 将资料同步到云端或局域网设备。
- 让某个 Skill 自动写入长期记忆。
- 把健康、家庭、工作等敏感资料发送到第三方模型。

## 资料安全

- `.env` 已被 `.gitignore` 排除。
- 本地资料默认不进入公开仓库。
- 对话上下文只包含当前领域最近的少量资料。
- 后续接入云模型时，应新增发送预览与按领域授权。
