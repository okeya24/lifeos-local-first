# 本地语音对话

## 已实现

- WhisperKit 本地语音识别
- 约 0.7 秒停顿后自动结束一轮说话
- 录音过程中每 1.4 秒更新一次预览字幕
- AI 回答按句子流式朗读
- AI 说话时检测用户插话
- 插话后立即停止播放和中断模型请求
- 使用 macOS 中文系统语音
- 默认不保存原始录音

## 启动

本机已通过 `com.lifeos.whisper` 自动启动识别服务。

手动启动：

```bash
pnpm voice
```

检查状态：

```bash
curl http://127.0.0.1:50060/v1/audio/transcriptions
curl http://127.0.0.1:8787/api/voice/status
```

## 使用

1. 打开 LifeOS 的 Cove 对话区。
2. 点击麦克风按钮。
3. 浏览器首次会请求麦克风权限。
4. 直接说话，真实问题和停顿会出现在语音状态卡内。
5. 停约 0.7 秒后自动提交。
6. AI 开始朗读后，再次说话即可插话打断。

推荐使用带回声消除的耳机，尤其当电脑扬声器音量较大时。

## 当前限制

- 端到端语音模型尚未接入，目前是“流式识别 → 本地模型 → 分句朗读”的流水线。
- 回答生成速度仍受 `qwen2.5:7b` 本地推理速度影响。
- 还没有唤醒词。
- 还没有保存/恢复未完成语音会话。
- 当前电脑没有检测到可用音频输入设备，真实麦克风仍需连接和授权。
