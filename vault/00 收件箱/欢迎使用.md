# 欢迎使用 LifeOS Local

这个 `vault/` 里全部是**虚构的示例笔记**，来自一个假想的不上班的独立开发者。
随便改、随便删——它们的作用只是让界面有东西可展示。

## 你可以先试这三件事

1. 打开界面，点中间的光球，看五只水母展开。
2. 读 [[睡眠与精力]]，注意右侧分析栏里的「反向链接」——它列出了所有提到这篇的笔记。
3. 把整个 `vault/` 换成你自己的笔记目录（见 README 的「换成你自己的笔记」）。

## 想写新笔记

在 `00 收件箱` 新建一个 `.md` 文件，开头写：

```yaml
---
title: 标题
date: 2026-11-01
tags: [标签]
---
```

然后用 `[[另一篇笔记]]` 建立链接，界面上就会出现连线。
