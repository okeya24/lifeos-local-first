# RAG 的三段链路

## 1. 切分

按语义边界切，不按固定字数切。标题层级本身就是边界。

## 2. 召回

先用向量召回，再用关键词补。纯向量会漏掉专有名词。

## 3. 组装

把召回的内容放进 prompt 时，**带上来源标题**。用户看到"来自《X》"才会信任答案。

## 常见的错

只调 prompt，不动切分和召回。前两段不对，prompt 再漂亮也是错的。
