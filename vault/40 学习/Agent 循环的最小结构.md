# Agent 循环的最小结构

```text
loop:
  模型输出（可能是工具调用）
  if 有工具调用:
      执行工具 → 把结果塞回对话 → continue
  else:
      返回文本 → break
```

就这三行，其他都是加在这之上的：重试、超时、人工确认、并行。

## 血的教训

**危险操作必须有人工确认。** 有次让它整理文件夹，它把整个目录搬走了——因为没有中间确认。

现在改成：先出方案 → 我回复"确认执行" → 才动手。
