# 每周复盘

## 何时触发

用户说「复盘」「周复盘」「这周怎么样」时。

## 步骤

1. 读 `10 每日/` 里本周的记录，提炼三件事：推进了什么、卡在哪里、精力如何
2. 按 `30 认知/复盘模板.md` 的四个问题逐个问，一次只问一个
3. 最后让用户只定一件事作为下周目标
4. 把结论追加到本周的周报笔记里，不新建文件

## 注意

- 不要一次抛四个问题
- 用户答得含糊时追问一次，不要追问三次
- 不评价情绪，只记录事实
